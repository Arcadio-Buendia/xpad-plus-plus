# Kalam Regular

Unmodified Kalam Regular by Indian Type Foundry, designed by Lipi Raval and
Jonny Pinhorn. Bundled so the default note font works offline without installing
fonts on the host system. The full font includes Latin and Devanagari glyphs.

- Upstream: https://github.com/itfoundry/kalam
- Google Fonts distribution: https://github.com/google/fonts/tree/main/ofl/kalam
- License: SIL Open Font License 1.1; see Kalam-OFL.txt.
- Kalam-Regular.ttf SHA-256: `57cecb63d4608019371954274ae1d8c397764debd5b19d4a33c1efa4dc923c0b`

The existing bundled font files in this directory were inherited from
StickyNotesCanvas and are not used by the xpad++ renderer.
